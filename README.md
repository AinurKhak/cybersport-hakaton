# cybersport-hakaton
Идея проекта: создать веб-приложение, которое автоматически собирает логотипы команд CS2 с сайта Cybersport.ru, анализирует их визуальные характеристики и применяет фильтры обработки изображений на основе NumPy и PyTorch. Пользователь может сравнить исходные и обработанные изображения, а также увидеть числовые характеристики каждого изображения.
