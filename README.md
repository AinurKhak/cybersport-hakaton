# ImageScope Hackathon API

**ImageScope** — REST API для парсинга, анализа и обработки изображений с веб-страницы `cybersport.ru`. Проект разработан в рамках хакатона и демонстрирует полный цикл работы с изображениями: от сбора ссылок на целевом сайте до применения фильтров с использованием NumPy и PyTorch.

---

## 📋 Возможности

- **Парсинг изображений** с сайта `cybersport.ru` с поддержкой пагинации.
- **Фильтрация и дедупликация** ссылок (только логотипы команд, без SVG и служебных элементов).
- **Устойчивое скачивание** изображений с проверкой `Content-Type` и размера.
- **Анализ статистики** каждого изображения:
  - Ширина и высота
  - Соотношение сторон
  - Средняя яркость
  - Контраст
  - Средний цвет RGB
- **Обработка изображений**:
  - Массивные операции через NumPy (инверсия, ручная конвертация в grayscale).
  - Свёртка через PyTorch (`F.conv2d` с ядром повышения резкости).
- **Веб-интерфейс** (Jinja2-шаблон) для визуального анализа.
- **Структурированный JSON-ответ** со статистикой, оригинальными и обработанными изображениями в Base64.
- **Отказоустойчивость**: retry-логика, имитация человеческого поведения (случайные задержки), graceful degradation.

## 🚀 Установка и запуск
1. Клонирование репозитория

bash `git clone https://github.com/AinurKhak/cybersport-hakaton.git
cd cybersport-hakaton`

2. Установка зависимостей

bash `pip install fastapi uvicorn httpx beautifulsoup4 numpy torch pillow jinja2 python-multipart`

3. Запуск сервера

bash `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`

* Сервер будет доступен по адресу: `http://localhost:8000`

📡 API Эндпоинты
GET /
Веб-интерфейс для визуального анализа изображений.
GET /health
Проверка работоспособности сервиса.
Ответ:

`{
  "status": "ok",
  "service": "hackathon_imagescope"
}`

POST /api/analyze
Основной эндпоинт для анализа изображений.
Тело запроса:

`{
  "filter_name": "default",
  "max_images": 100
}`
